# Portfolio Anna Maria Lima da Silva — Version Windows 98

Cette version est une version plus lisible et professionnelle avec une esthétique Windows 98 :

- fenêtres claires
- barres de titre bleues
- boutons style Windows classique
- texte noir sur fond clair
- section alternance
- meilleurs projets
- expériences avec projets associés
- formations avec logos
- icônes de technologies
- section langues
- contact, GitHub, LinkedIn et CV

## Fichiers

- `index.html`
- `style.css`

## À modifier avant publication

Dans `index.html`, remplacer :

- `https://github.com/VOTRE-UTILISATEUR` par le vrai lien GitHub.
- `https://www.linkedin.com/in/VOTRE-LINKEDIN` par le vrai lien LinkedIn.
- `LIEN-CALENDRIER-ALTERNANCE` par le lien officiel du calendrier d’alternance.

## CV PDF

Le bouton de téléchargement du CV pointe vers :

`assets/Anna_Maria_Lima_da_Silva_CV.pdf`

Pour qu’il fonctionne :

1. Créer un dossier `assets`.
2. Ajouter le PDF du CV dedans.
3. Nommer le fichier exactement : `Anna_Maria_Lima_da_Silva_CV.pdf`.

## Galerie photos

La galerie photo n’est pas affichée dans cette version.

Quand les photos seront sélectionnées, vous pourrez ajouter une section `Galerie photos` après les projets ou après les expériences.

Conseil : choisir 4 à 8 photos professionnelles maximum, avec des légendes courtes :

- projet LoRaWAN
- supervision Modbus TCP
- capteurs
- robotique
- banc d’essai
- installation technique

## Publication avec GitHub Pages

1. Créer un repository GitHub, par exemple `portfolio-anna-maria`.
2. Ajouter `index.html` et `style.css`.
3. Ajouter le dossier `assets` si vous voulez inclure le CV.
4. Aller dans `Settings > Pages`.
5. Choisir `Deploy from a branch`.
6. Sélectionner `main` et `/root`.
7. Sauvegarder.

Le site sera disponible à une adresse du type :

`https://votre-utilisateur.github.io/portfolio-anna-maria/`
